## Core product

Upload a business CSV/XLSX dataset. The platform profiles the data, lets a user ask business questions in natural language, uses an AI agent to choose bounded analysis tools, generates and validates SQL/Python analysis, detects trends and anomalies, produces charts, and creates an executive report.

## Important rule for AI-assisted development

Vibe coding is allowed as an implementation accelerator, but every developer must understand the code they own. Do not claim an algorithm, metric, model, test, or result that the team cannot explain and reproduce.

## Antigravity instruction

Read the master plan, technical contracts, your developer file and verification document completely. Inspect the existing checkout before changing anything. Work only in your assigned ownership area. Present one numbered task, its files and acceptance test; implement it, test it, summarize the result and wait for approval before continuing.

Never put credentials in code. Never execute arbitrary SQL generated by an LLM. Never fabricate analytics, model accuracy, test results, deployment status or business insights.
